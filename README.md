# Amelia Eckard Portfolio _(ameliaeckard.github.io)_

Source for ameliaeckard.com, my project pages, Lab links, and interactive resume.

## Background

The site is the public index for my software engineering, applied AI, research, teaching, and creative-technology work. The current focus is software systems, computer vision, spatial computing, and human-centered technology.

## Install

```bash
git clone https://github.com/ameliaeckard/ameliaeckard.github.io.git
cd ameliaeckard.github.io
bundle exec jekyll serve
```

If Jekyll is unavailable, the static assets can still be inspected directly; project discovery on the homepage uses Jekyll front matter.

## Usage

Edit project pages under `projects/`, resume data under `resume/`, and shared presentation in `styles.css` and `script.js`.
