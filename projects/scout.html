Scout

Internship & Hackathon Discovery Bot

Python discord.py SQLite SimplifyJobs Scheduled DMs

The Problem

Internship and hackathon listings move quickly, but most discovery tools either expect students to repeatedly check a website or send broad notifications that become easy to ignore. Scout is a Discord bot built for a student community that turns new opportunities into a lightweight, opt-in feed delivered where students already communicate.

The design deliberately avoids turning the server into an announcement wall. Students choose whether they want notifications at all, what kinds of opportunities they care about, and how often Scout should contact them. Scheduled updates are private, so opting in never creates noise for everyone else.

How Scout Works

Explicit Opt-In

Students choose whether Scout should notify them. No one is enrolled into opportunity alerts automatically.

Personalized Opportunity Types

Preferences can include internships, hackathons, or both, so each digest reflects what the student actually wants to see.

Daily or Weekly Delivery

Students can receive a daily digest or a weekly Sunday digest without changing the experience for anyone else in the server.

Private Discord Digests

Scheduled opportunity updates are sent directly to the student instead of posting repeated alerts into public channels.

Paginated Listings

Digests show five opportunities at a time with Previous and Next controls plus direct buttons for viewing the original posting or event.

Preference Controls

Students can revisit their settings, change delivery preferences, or unsubscribe without needing an administrator.

Source and Delivery Pipeline

Scout synchronizes internship listings from the SimplifyJobs Summer 2027 internship repository and uses a structured source for hackathon discovery. Source checks run incrementally, and the bot stores enough local state to recognize listings it has already seen instead of repeatedly notifying students about the same opportunity.

A persistent opportunity panel gives students a predictable place to open the same preference flow used by the slash command. The interface keeps setup private and lightweight, while scheduled delivery remains separate from the public server experience.

Technical Details

Scout is written in Python with discord.py and uses SQLite for subscription preferences, source state, and duplicate protection. Source synchronization is separated from delivery scheduling so discovering an opportunity and notifying a student are not treated as the same operation. This makes it possible to retry feeds, avoid duplicate messages, and support different schedules from the same shared opportunity pool.

The Discord UI is button-driven wherever that makes the interaction easier: opportunity type, frequency, pagination, preferences, unsubscribe, and direct posting links are all exposed without requiring students to memorize a collection of commands.
