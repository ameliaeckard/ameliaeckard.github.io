Iris Calliope

Roleplay Chronicle System

Python discord.py SQLite Fernet Encryption Self-Hosted LLM Railway

The Concept

Iris Calliope is a roleplay memory system for collaborative Discord storytelling. Long-running scenes create a lot of context very quickly, and the details that make a shared story feel coherent can disappear into months of channel history. Calliope exists to preserve the story itself without turning the people writing it into a dataset.

The bot stays silent while roleplay is happening. It watches only administrator-selected channels and accepts roleplay from trusted Tupperbox webhook sources. From that limited stream, it creates a temporary encrypted record that can be summarized, searched, and shaped into useful story memory later.

Privacy by Design

Calliope is intentionally narrow about what it records. It is built to narrate roleplay, not profile users. Raw roleplay text is retained for seven days and then removed, while summaries can remain as the long-term story record. The system does not score participation, rank writers, build identity profiles, or silently backfill old server history.

Trusted Sources Only

Administrators explicitly choose which channels and Tupperbox webhook sources Calliope is allowed to observe.

Seven-Day Raw Retention

Raw roleplay text exists only long enough to support recent context and summarization, then expires automatically.

Searchable Story Memory

Retained summaries make it possible to find characters, scenes, details, and past developments without digging through months of Discord history.

Story Suggestions

Calliope can suggest possible directions from retained context without treating those suggestions as canon.

Silent During Scenes

The bot does not interrupt active roleplay with commentary, scoring, or automated reactions.

Self-Hosted Inference

Language-model processing is designed around custom or self-hosted inference rather than sending roleplay text to a general external AI service.

Technical Details

Calliope is written in Python with discord.py and runs on Railway. Its working data is stored in SQLite on persistent storage, with sensitive retained content encrypted before it is written. The bot separates Discord collection, retention, search, summarization, and model inference so each part can fail independently without turning an active roleplay channel into a dependency on the AI layer.

The interaction layer keeps administrative controls explicit. Channel and source trust are configurable, search is invoked intentionally, and privacy-facing responses are kept ephemeral where appropriate. The result is a system that can remember a fictional world while keeping the scope of that memory understandable to the people using it.
