RoomCode

Browser-Based Collaborative Coding Environment

Python Vanilla JS WebSockets

The Idea

Pairing on code across a local network usually means screen sharing, which is laggy, one-directional, and gives only one person real control. RoomCode is a lightweight alternative: one person runs a small server pointed at a local project folder, and anyone else on the same network joins through a browser tab and gets a shared, editable view of the same files.

How It Works

The host runs a Python server against a folder on their machine. Guests connect over the local network with nothing to install, just a browser. Edits, cursor position, and selection are synced live between everyone in the room, and the host can set role-based permissions to control who can edit versus just view.

Features

Live Selection Highlighting

See exactly where everyone else in the room is looking and editing in real time.

File Drag-and-Drop

Add files to the shared project directly from the browser.

Role-Based Host Controls

The host decides who can edit and who can only view, per session.

Per-Session File Trees

Each room reflects the state of the host's folder as it changes, without needing a manual refresh.

Why It Exists

Most collaborative editors require an account, a cloud service, and an internet connection even when everyone involved is sitting in the same room on the same network. RoomCode skips all of that: no accounts, no cloud dependency, just a server and a browser tab.
