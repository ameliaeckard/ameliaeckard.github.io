Hera's Garden

Creative Studio and Community Ecosystem

Node.js Express Railway Discord Java MariaDB Minecraft Paper

What It Is

Hera's Garden is my personal creative and technical ecosystem, a home for writing, photography, software projects, community spaces, and game development. It operates under the Heraclid identity and connects a public website, Discord community, custom automation, and The Garden SMP instead of treating each project as an unrelated account on a different platform.

The visual direction is botanical, quiet, and deliberate, but the system underneath it is highly practical. I use Hera's Garden as a place to build the tools I wish existed for my own communities, then connect those tools through shared infrastructure so the experience feels consistent from the website to Discord to Minecraft.

The Website

herasgarden.net is a Node.js and Express application hosted on Railway with persistent storage. The public site surfaces creative work and community information, while Discord OAuth2 protects administrative tools and lets the site use the same community identity people already have instead of maintaining another password system.

Content management is intentionally lightweight and portable. The site favors simple structured storage and direct control over a large general-purpose CMS, which keeps the deployment understandable and makes the project easier to maintain independently.

The Ecosystem

Iris

The operational layer behind the community, including Discord automation, moderation, XP, private member channels, GitHub issue intake, calendar features, and the bridge into The Garden SMP.

Iris Calliope

A separate privacy-conscious roleplay memory system that watches approved story channels, keeps raw text temporarily, and preserves long-term narrative context through summaries rather than player profiling.

The Garden SMP

A Paper-based Minecraft server backed by a custom Java plugin suite for land, trade, civics, events, moderation, mail, cosmetics, and shared platform services, plus a custom resource pack and MariaDB-backed integration.

Community Infrastructure

Shared logging, account linking, event handoff, project tracking, and deployment infrastructure connect systems that run in different places without requiring them to be online at exactly the same moment.

Why Build It

The alternative is a collection of disconnected platforms: creative work in one place, community in another, game systems somewhere else, and no single view of how any of it fits together. Hera's Garden exists because I wanted those pieces to feel like one environment I can understand, design, and operate myself.

It is also a long-running engineering project. Maintaining the website, bots, game plugins, databases, integrations, and community workflows keeps me working across product design, backend systems, UI and UX, deployment, and the messy edge cases that only appear once software has real users.
