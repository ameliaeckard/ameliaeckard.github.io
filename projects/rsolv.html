R'Solv

Human-in-the-Loop Exception Review

Python Flask Amazon Bedrock Claude XGBoost

What It Is

R'Solv is a beneficiary-claim exception review prototype built for the LPL Financial University Hackathon. It reads claim documents, extracts structured case information, checks explicit requirements, and gives reviewers a second model signal without turning the system into an automatic approval engine.

Project Team

R'Solv was developed collaboratively by Amelia Eckard, priyapo, j-pegu, and MKHunt-bit for the LPL Financial University Hackathon.

Why the System Is Split

Different parts of the problem call for different tools. Claude through Amazon Bedrock handles the fuzzy work of interpreting document language and turning it into structured facts. Deterministic rules handle requirements that should be explicit and reproducible. XGBoost acts as an additional signal rather than a replacement for those rules.

Document Understanding

Extracts structured case information from beneficiary claim PDFs using Claude through Amazon Bedrock.

Deterministic Checks

Evaluates explicit requirements with rules that are visible and repeatable instead of asking a model to guess everything.

Secondary ML Signal

Uses XGBoost alongside the rule system and surfaces disagreements rather than hiding them.

Human Review

Keeps approval and financial decisions with the reviewer while presenting the evidence and reasoning needed to investigate exceptions.

Design Principle

R'Solv is an example of how I prefer to use AI: for a bounded part of a workflow where it is useful, surrounded by conventional software where conventional software is more reliable, and with a person retaining the final decision.
